# 现场问题客户选择采用受控搜索

新建现场问题的客户字段从原生下拉升级为受控 Combobox，以解决客户目录较长时难以定位的问题；搜索只对客户名称和三平台分支做不区分大小写的连续子串筛选，只有确认候选项才会更新问题记录。保留客户目录作为唯一有效来源，不允许把搜索词作为客户提交，也不提供创建目录外客户的入口。

## Considered Options

- 保留原生 `<select>`：继续限制自由输入，但无法稳定支持按客户名或分支名筛选。
- 允许普通文本输入：搜索体验简单，但会破坏客户目录约束和服务端字段契约。
- 采用受控 Combobox：兼顾长列表检索、键盘/读屏可用性和配置驱动约束，已采纳。

## Consequences

- 搜索结果保持客户目录原顺序，展示客户名及分支后缀，但提交值仍为客户名称。
- 临时搜索词与已确认客户分离；无匹配、点击外部或按 Esc 都不会改变已确认客户。
- 配置无效时控件继续禁用并显示现有错误提示；长结果列表在候选面板内部滚动。
- 新交互必须满足标准 Combobox 无障碍语义，并覆盖键盘选择、无匹配和配置驱动等回归测试。
