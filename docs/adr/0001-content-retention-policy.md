# 自动内容保留策略

应用每天按服务器本地时间 12:00 清理最后活动时间超过 7×24 小时的聊天会话索引和现场分析内容。现场问题以数据库、关联会话和磁盘文件的最新活动时间为准；只保护存在正在运行会话的问题，不因 `analyzing` 状态无限保留。日期前缀的孤儿问题目录也会递归删除，但根目录文件、隐藏目录和非业务目录永久保留。现场目录先删除、成功后删除 SQLite 索引；Claude Code 的 `~/.claude/` 文件、项目索引及账号/凭据/配置等系统基础数据永久保留。这个边界优先保证活跃分析和系统基础资料，避免无效索引或未结束状态导致磁盘内容永久积累。
